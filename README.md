# psiangelo-posts

Imagens dos posts de citações do Instagram [@psiangelo](https://instagram.com/psiangelo), hospedadas para agendamento automático (Publer / Metricool / etc.).

Cada arquivo é referenciado por URL pública no formato:

```
https://raw.githubusercontent.com/Psiangelo/psiangelo-posts/main/<NOME_DO_ARQUIVO>
```

As legendas e o calendário correspondente estão no arquivo `posts_agendamento.csv` (fora deste repositório).
